# Industrial Invoice Manager

Secure, full-stack invoicing portal built for a service-based business. Lets an
authenticated admin itemize project costs (materials, labor, custom line items) and
generate client-ready invoices.

## Features
- Login-gated access (session auth)
- Custom line items for materials and labor
- Automatic invoice total calculations
- Per-invoice status tracking (paid/unpaid)
- Client billing export

## Tech Stack
- Django
- SQLite
- Django session-based authentication
- Render (hosting)
